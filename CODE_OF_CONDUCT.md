# Code of Conduct

Highcharts Angular is a [Highcharts](https://www.highcharts.com) project by Highsoft AS. Conduct in this project follows the [Highsoft Code of Business Conduct and Ethics](https://www.highcharts.com/code-of-business-conduct-and-ethics).

## Reporting

To report conduct that conflicts with this Code, use the reporting contact given in the Code: [hr@highsoft.com](mailto:hr@highsoft.com).
